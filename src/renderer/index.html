      ❓ Aide — où trouver chaque information ?

      Nom du serveur — un nom libre pour le retrouver dans ta liste (ex : le nom de ta communauté).

      Adresse IP — l'adresse publique de la machine qui héberge le serveur Minecraft. Pour la trouver, connecte-toi sur cette machine et tape curl ifconfig.me (IP publique, joignable depuis Internet) ou hostname -I (IP locale, si ton PC est sur le même réseau que le serveur).

      Port query — le port du jeu : dans server.properties, ligne server-port (25565 par défaut). Sert à voir le statut et les joueurs sans mot de passe. À activer : enable-query=true + query.port=25565.

      Port RCON — rcon.port dans server.properties (25575 par défaut).

      Mot de passe RCON — tu le choisis toi-même : dans le dossier du serveur, ouvre server.properties, mets rcon.password=TON_MOT_DE_PASSE_FORT et enable-rcon=true, puis redémarre le serveur. Recopie ici exactement ce mot de passe.

      Pare-feu — ouvre les ports 25565/udp et 25575/tcp sur la machine du serveur : sudo ufw allow 25565/udp et sudo ufw allow 25575/tcp. Sur un VPS, ouvre-les aussi dans le pare-feu du fournisseur (panneau web).

      SSH (logs en direct) — pour afficher le chat et les logs du serveur dans la page Console : remplis le port SSH (22), ton utilisateur SSH et ton mot de passe SSH. Côté serveur, autorise le mot de passe : PasswordAuthentication yes dans /etc/ssh/sshd_config, puis sudo systemctl restart ssh. Sans SSH, l'appli marche quand même, juste sans les logs en direct.

      Dossier du serveur — le chemin complet du dossier où se trouve server.jar. Pour le trouver : connecte-toi en SSH sur la machine du serveur, place-toi dans le dossier du serveur, puis tape pwd : le terminal affiche le chemin complet (exemple : /home/leon/minecraft). Copie ce chemin dans ce champ (tu peux aussi écrire ~/minecraft). Ne mets pas de commande, juste le chemin. Vérifie que l'utilisateur SSH a bien le droit de lire les fichiers de ce dossier. Ce champ sert uniquement à lire les logs en direct.
