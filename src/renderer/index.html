    À configurer sur TON serveur — clique sur un bloc pour copier

    1. Dans server.properties, puis redémarre le serveur :

    enable-query=true
query.port=25565
enable-rcon=true
rcon.port=25575
rcon.password=TON_MOT_DE_PASSE_FORT

    2. Ouvre les ports dans le pare-feu :

    sudo ufw allow 25565/udp
sudo ufw allow 25575/tcp

    Sur un VPS : ouvre aussi 25565/udp et 25575/tcp dans le pare-feu du fournisseur.

    3. Logs en direct (page Console) — clé SSH :

    ssh-keygen -t ed25519
ssh-copy-id leon@IP_DU_SERVEUR

    La clé est détectée automatiquement dans l'appli. Sans SSH, l'appli marche quand même, juste sans les logs en direct.
